GHOST PROTOCOL MOBILE — GUIDE DE DÉPLOIEMENT

1. Cette archive contient un site web STATIQUE prêt à héberger.
2. Importez le CONTENU du dossier Ghost_Protocol_Mobile dans Netlify Drop, Cloudflare Pages ou GitHub Pages (support HTTPS).
3. Copiez l’URL créée pour la diffuser aux participants (et fabriquer un QR code).
4. Un fichier index.html ouvert directement sur ordinateur permet aussi un aperçu.
5. Chaque participant sauvegarde SA progression dans son navigateur (localStorage). Il n’y a ni compte serveur, ni synchronisation entre téléphones, ni leaderboard, ni statistiques centrales. Effacer les données du navigateur efface la progression.
6. Le site ne doit PAS contenir les PDF de corrigés ni les fiches confidentielles. Ces documents ne figurent pas dans cette archive.
7. Les codes sont comparés localement à des empreintes (un code de 4 chiffres n’est pas secrètement protégé contre quelqu’un qui inspecte le JavaScript). Pour une anti-triche sérieuse et un suivi centralisé, prévoir un backend avec validation côté serveur.
8. Dossier 003 : la séquence de traces ouvre la visualisation de la Carte B mais le témoin reste à rencontrer physiquement.
9. Dossier 004 : les fragments ne sont pas affichés en ligne. Il faut rencontrer les deux complices.
10. Les cartes A/B et les dossiers PDF sont reproduits à partir du ZIP fourni par l’organisateur.

NOTE DE CONCEPTION : la grille numérique possède le repère D1 sur la lettre U de ICLOUD pour produire UN, conformément au corrigé officiel ; sur l’impression, le repère D1 semble légèrement décalé sur la lettre D.

Dernière vérification avant diffusion : tester tous les codes sur deux téléphones et obtenir l’accord des collègues complices.
